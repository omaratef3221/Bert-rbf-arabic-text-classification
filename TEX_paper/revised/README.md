## Sources

* Main file: `TEX_paper/elsarticle/manuscript_revised.tex` (the submitted version `manuscript.tex` is untouched).
* Revision markup lives in the same file: `\rev{...}` around new or changed text and `\revblock` at the top of new floats (both defined in the preamble). A plain compile gives the marked copy; defining `\revclean` first gives the clean copy (see below). The markup is generated by `revision/mark_revisions.py` from the curated list `CURATED` at the top of that script (passages, sentences, headings and floats keyed to the reviewer points); edit the list and re-run the script after changing the text. `--mode diff` instead marks every sentence that differs from `manuscript.tex`, which colours most of the paper because it was rewritten.
* Result tables: `TEX_paper/elsarticle/tables/*.tex`, generated by `revision/make_tables.py` from `revision/results/paper_numbers.json`. Do not edit the `.tex` tables by hand; change the generator and rerun it.
* Figures: `TEX_paper/Figures_revised/*.pdf`, generated by `revision/make_figures.py` from `revision/results/`.
* References added in this revision: `TEX_paper/references_revision.bib` (loaded together with `references.bib`).
* Tracked-changes source: `TEX_paper/elsarticle/manuscript_tracked_changes.tex` (latexdiff output; tables inlined, standalone).

## Rebuilding everything

```
python revision/make_tables.py            # result tables from revision/results/paper_numbers.json
python revision/make_figures.py           # figures
python revision/mark_revisions.py         # blue markup (curated list CURATED in the script)
zsh TEX_paper/build_revised.sh            # marked, clean and tracked-changes PDFs into TEX_paper/build_rev/
zsh TEX_paper/package_revised.sh          # copies the PDFs here and rebuilds overleaf_upload.zip
python revision/letter_locations.py TEX_paper/revised/manuscript_revised_tracked_changes.pdf   # page/line index for the letter
```

Appendix B (label vocabulary, Table B.1; invalid-output breakdown, Table B.2) is generated from the mapper's constants in `revision/llm_eval.py` and from the raw output logs by the editing script of 30 Oct 2026; its two table files live in `elsarticle/tables/`.

## Compiling

The manuscript needs **LuaLaTeX** (fontspec + the Amiri font for the Arabic excerpts, babel with `bidi=basic` so that digits inside Arabic text keep their direction). From `TEX_paper/elsarticle/`:

```
latexmk -lualatex -bibtex manuscript_revised.tex                       # marked copy (blue changes)
latexmk -lualatex -bibtex -usepretex -pretex='\def\revclean{1}' \
        -jobname=manuscript_revised_clean manuscript_revised.tex     # clean copy
```

On Overleaf: upload `overleaf_upload.zip` as a new project, then Menu → Compiler: **LuaLaTeX**, Main document: `manuscript_revised.tex`. Amiri is part of TeX Live, no font upload needed. A plain Overleaf compile produces the marked copy; for the clean copy add the line `\def\revclean{1}` above `\documentclass`. `manuscript_tracked_changes.tex` compiles in the same project (set it as main document temporarily).
