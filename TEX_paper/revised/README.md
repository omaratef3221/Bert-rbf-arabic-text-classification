## Sources

* Main file: `TEX_paper/elsarticle/manuscript_revised.tex` (the submitted version `manuscript.tex` is untouched).
* Revision markup lives in the same file: `\rev{...}` around new or changed text and `\revblock` at the top of new floats (both defined in the preamble). A plain compile gives the marked copy; defining `\revclean` first gives the clean copy (see below). The markup is generated by `revision/mark_revisions.py`, which compares every sentence, heading and caption with `manuscript.tex`; re-run it after editing the text.
* Result tables: `TEX_paper/elsarticle/tables/*.tex`, generated by `revision/make_tables.py` from `revision/results/paper_numbers.json`. Do not edit the `.tex` tables by hand; change the generator and rerun it.
* Figures: `TEX_paper/Figures_revised/*.pdf`, generated by `revision/make_figures.py` from `revision/results/`.
* References added in this revision: `TEX_paper/references_revision.bib` (loaded together with `references.bib`).
* Tracked-changes source: `TEX_paper/elsarticle/manuscript_tracked_changes.tex` (latexdiff output; tables inlined, standalone).

## Compiling

The manuscript needs **LuaLaTeX** (fontspec + the Amiri font for the Arabic excerpts, babel with `bidi=basic` so that digits inside Arabic text keep their direction). From `TEX_paper/elsarticle/`:

```
latexmk -lualatex -bibtex manuscript_revised.tex                       # marked copy (blue changes)
latexmk -lualatex -bibtex -usepretex -pretex='\def\revclean{1}' \
        -jobname=manuscript_revised_clean manuscript_revised.tex     # clean copy
```

On Overleaf: upload `overleaf_upload.zip` as a new project, then Menu → Compiler: **LuaLaTeX**, Main document: `manuscript_revised.tex`. Amiri is part of TeX Live, no font upload needed. A plain Overleaf compile produces the marked copy; for the clean copy add the line `\def\revclean{1}` above `\documentclass`. `manuscript_tracked_changes.tex` compiles in the same project (set it as main document temporarily).

## Known cosmetic points of the tracked-changes copy

* Deleted section headings still consume a section number, so a few numbers repeat (e.g. two "3.3").
* "??" inside red (deleted) text are cross-references to tables and figures that no longer exist.
* Line numbers restart from the title page and differ from the clean copy.
